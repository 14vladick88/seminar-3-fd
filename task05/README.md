# 05. Уведомление о поездке · дополнительно, 15 минут

Темы: интерфейс, композиция, передача зависимости через конструктор.
Откройте `src/main/kotlin/seminar/task05/TripService.kt`.

Интерфейс `Notifier` и рабочий `TravelCard` уже даны. Это отдельные типы в пакете `seminar.task05`,
поэтому задачу можно решать независимо от task03. Не изменяйте их.

Реализуйте `TripService(private val notifier: Notifier)` и метод `travel(card: TravelCard): Boolean`:

1. Выполнить одну попытку поездки через `card.ride()`.
2. При отказе вернуть `false`, не отправлять сообщения.
3. При успехе отправить через переданный `notifier` ровно одно сообщение:
   `Поездка оплачена. Осталось поездок: N`, где N — остаток **после** списания.
4. Вернуть `true`.

Сервис работает с любым `Notifier` и с разными картами. Не создавайте свой уведомитель внутри сервиса.
`println` вместо `notifier.send` не считается отправкой. Считайте, что уведомитель работает без ошибок.

Пример: для карты с остатком 1 первый вызов вернёт `true` и отправит
`Поездка оплачена. Осталось поездок: 0`. Второй вернёт `false` без нового сообщения.
