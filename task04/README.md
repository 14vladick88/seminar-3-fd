# 04. Доставка

Служба доставки предлагает самовывоз, обычного курьера и экспресс-доставку. Создайте классы самостоятельно в файле [Delivery.kt](src/main/kotlin/seminar/task04/Delivery.kt).

## Общий тип

Абстрактный класс `Delivery` принимает в конструкторе `destination: String` и хранит его в доступном для чтения свойстве `destination: String`. Изменять адрес после создания нельзя. Пустой адрес и адрес только из пробельных символов запрещены: `IllegalArgumentException`. Допустимый адрес сохраняется без изменений.

У класса два метода:

- `cost(weightKg: Int): Int` — абстрактный метод расчёта стоимости в целых рублях.
- `label(weightKg: Int): String` — общий метод, возвращающий строку `Доставка в <адрес>: <стоимость> руб.`. Стоимость определяется реализацией `cost` конкретного объекта.

## Виды доставки

Все три класса наследуются от `Delivery`:

- `Pickup(destination: String)` — самовывоз, стоимость 0 при любом допустимом весе.
- `CourierDelivery(destination: String)` — 200 рублей за заказ и ещё 50 рублей за каждый килограмм.
- `ExpressDelivery(destination: String, distanceKm: Int)` — 300 рублей за заказ, 80 рублей за каждый килограмм и 20 рублей за каждый километр. Расстояние должно быть положительным, иначе конструктор выбрасывает `IllegalArgumentException`. Экспресс-доставка принимает только посылки весом до 10 кг включительно.

Каждый `cost` отклоняет нулевой и отрицательный вес с `IllegalArgumentException`. Экспресс-доставка таким же образом отклоняет вес больше 10 кг. Эти правила действуют и при вызове `label`.

Один и тот же объект можно использовать для расчёта нескольких посылок. Ошибка при одном расчёте не должна влиять на последующие.
Добавление нового наследника не должно требовать изменения `label`: проверки конкретных классов внутри него запрещены.

Входные положительные значения веса и расстояния не превышают 10 000. Дополнительных ограничений для обычного курьера и самовывоза нет.

## Пример

Для `ExpressDelivery("Школа", 4)` посылка весом 2 кг стоит 540 рублей.
Вызов `label(2)` возвращает `Доставка в Школа: 540 руб.`.

Сохраните строку `package` в файле. Имена классов, параметров, свойств и методов должны соответствовать условию. Пока классы не созданы, тесты этой задачи не компилируются — это ожидаемо.
