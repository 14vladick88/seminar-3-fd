# 01. Два дополнительных разряда

На вход алгоритма поступает натуральное число N.

1. Запишите N в двоичной системе без ведущих нулей.
2. Если N чётное, добавьте к записи справа `00`. Если нечётное — `11`.
3. Переведите полученную запись в десятичную систему. Это результат R.

Например, для N = 6: `110 → 11000`, поэтому R = 24.
Для N = 5: `101 → 10111`, поэтому R = 23.

В файле `src/main/kotlin/seminar/task01/BinarySuffix.kt` реализуйте две функции:

- `transform(n: Int): Int` — возвращает R для заданного N.
- `maxNBelow(limit: Int): Int` — возвращает **наибольшее N**, для которого R **строго меньше** limit. Если такого натурального N нет, верните 0.

Ограничения: `1 ≤ n ≤ 10 000`, `1 ≤ limit ≤ 40 000`.
При поиске достаточно проверить N от 1 до 10 000 включительно. Входные данные корректны, проверять их не нужно.

| Вызов | Результат |
|---|---|
| `transform(6)` | `24` |
| `transform(5)` | `23` |
| `maxNBelow(134)` | `32` |
| `maxNBelow(7)` | `0` |

Верните результат из функции. Читать ввод и печатать ответ не нужно.

<details><summary>Подсказка по Kotlin</summary>

`n.toString(2)` — двоичная запись числа. `"101".toInt(2)` — число из двоичной записи.
Строки соединяются через `+`. Чётность проверяется через `n % 2`.
Для перебора используйте `for (n in 1..10_000)`.

</details>
