# 02. Биты чётности

На вход алгоритма поступает натуральное число N.

1. Запишите N в двоичной системе без ведущих нулей.
2. Посчитайте сумму цифр этой записи. Добавьте справа её остаток от деления на 2 — один символ, `0` или `1`.
3. Повторите шаг 2 для **уже изменённой записи**: заново посчитайте сумму цифр и добавьте ещё один символ.
4. Переведите итоговую запись в десятичную систему. Это результат R.

Например, для N = 131: `10000011 → 100000111 → 1000001110`, поэтому R = 526.

В файле [ParityBits.kt](src/main/kotlin/seminar/task02/ParityBits.kt) реализуйте две функции:

- `transform(n: Int): Int` — возвращает R для заданного N.
- `minNAbove(limit: Int): Int` — возвращает **наименьшее N**, для которого R **строго больше** limit.

Ограничения: `1 ≤ n ≤ 10 000`, `0 ≤ limit ≤ 39 999`.
При поиске достаточно проверить N от 1 до 10 000 включительно. Решение всегда существует, входные данные корректны.

Верните результат из функции. Читать ввод и печатать ответ не нужно.
